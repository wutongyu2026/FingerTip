## 0. 背景 & 触发

v0.2.5 通过 code review 识别 21 个 finding，其中：
- 🔴 必修 8 个：用户可见的占位 / 假数据
- 🟡 重要 5 个：架构语义不一致 / 链路断裂
- 🟢 优化 3 个：死代码 / 代码味道
- 🔵 信息 5 个

必修都集中在「作品页是真的作品」与「心情真的影响生成」。v0.3 目标：清空必修 + 重要，
交付一个无任何 UI 占位 / 无任何数据假象的版本。

v0.3 还是 major 升级因为会破坏内部 Rust API（trait 重命名 + 模块重组）。

### 2.2 Adapter Trait 定义

```rust
// src-tauri/src/generate/mod.rs
use async_trait::async_trait;

pub mod local;
pub mod cloud;

#[derive(Debug, Clone)]
pub struct MusicPrompt {
    pub events: Vec<KeyEvent>,
    pub mood: Option<String>,
    pub style: String,
    pub theme_word: String,
}

#[derive(Debug, Clone, serde::Serialize)]
pub struct Music {
    pub notes: Vec<NoteSpec>,         // 已有
    pub bpm: u32,
    pub duration_ms: u64,
    pub amplitudes: Vec<f32>,         // 64 sample points
    pub mood: Option<String>,
}

#[async_trait]
pub trait MusicAdapter: Send + Sync {
    fn name(&self) -> &'static str;
    async fn generate(&self, prompt: &MusicPrompt) -> anyhow::Result<Music>;
}

// 同样 ArtPrompt / Art / ArtAdapter
```

### 2.3 Adapter Factory

```rust
// src-tauri/src/generate/mod.rs
pub fn build_music_adapter() -> Box<dyn MusicAdapter> {
    if std::env::var("FINGERTIP_USE_CLOUD").is_ok() {
        Box::new(cloud::music::CloudMusicAdapter)
    } else {
        Box::new(local::music::LocalMusicAdapter)
    }
}
```

### 2.4 数据流（mood 真实持久化）

```
[SubmitMood.vue]
   submit → invoke('set_mood', { date, mood })
                      ↓
   [commands::set_mood]
      SummaryRepo::upsert_mood(date, mood)
                      ↓
   [SQLite: daily_summary.mood_word]  ← 不再 NULL
                      ↓
   invoke('generate_now', { date, mood, style })
                      ↓
   [commands::generate_now]
      ↓ 用 build_music_adapter() 选 LocalMusicAdapter
      LocalMusicAdapter::generate({ events, mood, style, theme_word })
                      ↓
   [returns Music{ notes, bpm, duration_ms, amplitudes, mood }]
                      ↓
   [frontend renders: 波形 + 时长 + 心情标签]
```

### 2.5 错误处理

| 错误 | 处理 |
|---|---|
| `CloudMusicAdapter::generate` 启用 cloud 但无 key | 返回 `Err("cloud adapter requires FINGERTIP_CLOUD_KEY env (v0.4 feature)")` |
| `LocalMusicAdapter::generate` events 为空 | 仍可生成（用 mood/style 默认节奏），返回 `Ok(Music{ ... })` |
| Tauri dialog save 用户取消 | 静默 `Ok(())` 不弹错误 |
| plugin-fs 写盘失败 | 弹 `n-message` 错误 toast，不阻塞其他下载 |
| mood 字符串过长（>64 字符）| 后端 truncate 到 64 + 日志 warn |

## 3. E2E 验收用例

> 用 `pnpm playwright test`（或 `playwright-cli` 单独执行）跑。
> 每个 case 都是 first-class test，不依赖其他 case。
> **dev mode**：`pnpm tauri dev` 启动后自动开 webview。

| ID | 用例 | 断言 |
|---|---|---|
| **E2E-A** | SubmitMood → 提交 "开心 / Jazz" → 跳转 Artworks | Music 卡片顶部出现「Jazz · 120bpm · 32s · 开心」标签；波形 36 条 bar **高度不一致且与回放一致**；时长显示非 0:14 |
| **E2E-B** | Artworks → 等待渲染完成 | 占位 div `abstract` 文字消失；真 `<img>` 显示；canvas 真有像素 dataURL；mood 标签 `开心` 显示 |
| **E2E-C** | Artworks → 点下载 png → 弹 Tauri Save As | 默认目录 = 设置页配置的目录；默认文件名匹配 `FingerTip-art-*.png`；确认后文件写入 + 文件头 `89 50 4E 47` |
| **E2E-D** | Today → 点心情链接 → 提交 → 重启 app → 回到 Today | mood 显示非空（持久化验证） |

每个 case 跑通前不能进入下一阶段。

## 4. 实施顺序（5 Stage）

| Stage | 内容 | 验收 | E2E |
|---|---|---|---|
| **S1** 后端 trait 重构 + 删 stub | trait 定义 / Local impl / Cloud 占位 / 删 minimax_cloud / 删 trigger_generate / 删 scheduler 死代码 | `cargo test --lib` 113+ pass | — |
| **S2** data 层 mood | `SummaryRepo::upsert_mood` + `set_mood` command | `cargo test --lib` 118+ pass | — |
| **S3** Local adapter 真生成 | mood → bpm/调性，theme_word → amplitudes/pixels | `cargo test --lib` 130+ pass | — |
| **S4** 前端真实渲染 | Artworks 占位 → 真 `<img>`；波形读 amplitudes；时长读 durationMs；删除 Settings 死 UI；Today dataSource 简化 | `pnpm test` 80+ pass；`pnpm typecheck` 0 error | E2E-A + E2E-B |
| **S5** 下载 + Tauri 插件 | 下载目录设置 / dialog.save / plugin-fs / 首次引导默认目录 | 手动跑 E2E-C + E2E-D | E2E-C + E2E-D |

每个 Stage 完成后：
1. cargo test / pnpm test / pnpm typecheck 全过
2. 输出 diff summary（一段话）：改了什么 + 测试结果
3. 用户简短 ack "ok" 再进下一 Stage
